# 🎮 C Number Guessing Game

A simple number guessing game developed using **C programming**.

## 📌 About the Project

This program generates a random number between **1 and 100**.  
The user has to guess the number, and the program provides hints whether the guessed number is higher or lower than the actual number.

The program also counts the total number of guesses taken by the user.

## 🚀 Features

- 🎲 Random number generation
- 🔼 Higher number hint
- 🔽 Lower number hint
- 🔢 Counts number of attempts
- 🎉 Displays success message

## 🛠️ Concepts Used

- C Programming
- `if-else`
- `do-while` loop
- `rand()`
- `srand()`
- `scanf()` and `printf()`
- Basic logic and problem solving
